# 암호학 실험실 (Cryptography Lab)

학부 암호학 수업용 브라우저 시뮬레이터입니다. `index.html` 파일 하나로 동작하고, 설치나 서버가 필요 없습니다. 모든 계산은 브라우저 안에서만 이루어지며 입력값은 어디에도 전송되지 않습니다.

## 실행

`index.html`을 브라우저로 여세요. 주소 끝에 `#rsa`처럼 실험 이름을 붙이면 그 실험으로 바로 열립니다
(`classic`, `modular`, `rsa`, `dh`, `aes`, `modes`, `hash`, `ecc`).

## 실험 구성

| # | 실험 | 직접 해 보는 것 |
|---|---|---|
| 1 | 고전 암호 | 카이사르·비즈네르 암호화, 글자 빈도 그래프, χ² 전수 조사, 일치지수(IC)로 키 길이 추정 후 자동 해독 |
| 2 | 모듈러 산술 | 확장 유클리드 표와 모듈러 역원, 제곱-곱셈법 단계표와 곱셈 횟수 |
| 3 | RSA | 소수 생성(8–40비트), 키 계산, CRT 복호, 곱셈 준동형, 결정적 암호화의 약점, 시행 나눗셈·폴라드 ρ 인수분해 공격 |
| 4 | 디피–헬만 | 안전소수·생성원, 3자(앨리스·밥·이브) 화면, 중간자 공격, 전수 조사 대 아기걸음-거인걸음 이산로그 |
| 5 | AES-128 | 라운드·단계별 상태 행렬(바뀐 바이트 강조), 라운드 키, 1비트 눈사태 효과 |
| 6 | 블록 운용 모드 | 같은 그림을 ECB·CBC·CTR로 암호화, CTR nonce 재사용 시 C₁⊕C₂로 평문 윤곽 노출 |
| 7 | SHA-256 | 비트 단위 눈사태 격자, 출력을 n비트로 자른 생일 공격과 이론값 비교 |
| 8 | 타원곡선 | F_p 위 점 그림, 눌러서 P+Q·2P 계산 과정 보기, 더블-앤드-애드, 부분군, 미니 ECDH |

각 실험에는 핵심 개념(수식), 조작 패널, 관찰 결과, '생각해 볼 문제'가 들어 있습니다.

## 검증

구현은 다음 공개 시험값으로 확인했습니다.

- AES-128: FIPS-197 부록 C.1 (`69c4e0d86a7b0430d8cdb78070b4c55a`), 부록 A.1 키 확장 마지막 워드(`b6630ca6`)
- SHA-256: FIPS 180-4 예제 `"abc"`, 448비트 메시지, 1000바이트·한글 입력을 Node.js `crypto` 결과와 대조
- RSA: 교과서 예제(p=61, q=53, e=17 → d=2753), 무작위 24비트 키 200개로 암·복호와 CRT 왕복
- 타원곡선: y² = x³ + 2x + 3 (mod 97)에서 결합법칙 무작위 검사, 점 위수가 #E의 약수인지(라그랑주), 스칼라 곱과 반복 덧셈 일치

## 주의

교육용 구현입니다. 패딩 없는 RSA, 상수 시간이 아닌 연산, 작은 매개변수를 일부러 씁니다. 실제 시스템에는 검증된 라이브러리(예: libsodium, Web Crypto API, OpenSSL)를 쓰세요.
